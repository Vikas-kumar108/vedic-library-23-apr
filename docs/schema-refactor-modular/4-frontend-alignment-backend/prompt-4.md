After completing implementation:

1. Run:
   git add .

2. Create a structured commit:
   git commit -m "<TYPE>: <TITLE>

<WHAT>
- bullet points of changes

<WHY>
- reason for change

<IMPACT>
- what this improves"

3. Push:
   git push origin main

Rules:
- Use meaningful commit types:
  feat, fix, refactor, perf, docs

- Keep commits atomic (one logical change per commit)

- NEVER skip commit
- NEVER use vague messages like "update" or "fix"
